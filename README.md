## 📌 Sobre o Projeto:

Este projeto consiste em uma aplicação web desenvolvida como uma **Atividade Extensionista** voltada para atender às necessidades reais de agendamento e gestão de atendimentos de uma clínica odontológica. 
A aplicação permite que pacientes realizem seus agendamentos de forma simples e intuitiva, além de fornecer aos administradores/recepção o controle total sobre a agenda, dentistas e procedimentos.

### 🎯 Alinhamento com os Objetivos de Desenvolvimento Sustentável (ODS)
- **ODS 3 - Saúde e Bem-Estar:** Facilita o acesso dos pacientes a serviços odontológicos e incentiva os cuidados com a saúde bucal.
- **ODS 8 - Trabalho Decente e Crescimento Econômico:** Otimiza os processos operacionais e a organização da rotina da clínica.

## 🚀 Tecnologias Utilizadas:

- **Front-end:** React.js, HTML5, CSS3, JavaScript (ES6+)
- **Back-end:** Node.js, Express.js (API RESTful)
- **Banco de Dados:** PostgreSQL / MySQL
- **Nuvem & Infraestrutura:** AWS (Amazon Web Services), Git, GitHub

---

## 🛠️ Arquitetura do Sistema:

O projeto é dividido nas seguintes disciplinas do módulo:
1. **Integração de Dados:** Modelagem e persistência no Banco de Dados, garantindo consistência e integridade das regras de negócio.
2. **Tecnologias para Desenvolvimento Web:** API RESTful robusta com endpoints para controle de pacientes, consultas e horários.
3. **Desenvolvimento de Interfaces de Usuário para Web:** SPA (Single Page Application) responsiva desenvolvida em React.
4. **Computação em Nuvem:** Hospedagem na AWS e análise comparativa de custos entre AWS, Azure e Google Cloud.
5. **Arquitetura MVC (Model View Controller)**

---

## 📋 Funcionalidades Principais

- [ ] **Área do Paciente:**
  - Visualização de horários e datas disponíveis.
  - Agendamento de consultas com escolha do procedimento/dentista.
  - Confirmação e cancelamento de consultas.
- [ ] **Área Administrativa (Clínica):**
  - Painel/Dashboard de consultas agendadas.
  - Cadastro e gerenciamento de dentistas e procedimentos.
  - Gestão de horários de atendimento.
